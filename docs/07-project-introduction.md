# AgriScout 项目详细介绍（v1.0，2026-08）

> 用途：团队理解对齐 + 大挑申报书/答辩 PPT 的内容底稿。

## 一、项目概述

- **名称**：AgriScout —— 农田哨兵
- **定位**：面向农作物全生命周期的低成本高密度近地巡检与智能决策系统
- **一句话**：田间巡检小车每 0.5 米拍照并同步采集天气数据，平台自动判断作物生育期、长势与病虫害风险，输出可追溯的农事建议，形成"监测→诊断→建议"全生命周期闭环。

## 二、背景与痛点

1. **病虫害损失巨大**：作物病害具有强空间聚集性，早期斑块直径可小于 1 米，漏检即扩散；一次爆发可致亩产值损失 30–50%（如柑橘溃疡病、黄龙病）。
2. **人工巡田低效**：一名农技员日巡 50–100 亩已是极限，且依赖经验、不可量化、不可追溯。
3. **现有监测手段存在盲区**：

| 方案 | 分辨率 | 频次 | 盲区 |
|------|--------|------|------|
| 卫星遥感 | 0.5–10 m | 数天 | 云遮挡、看不见早期病害 |
| 无人机 | cm 级 | 按需 | 冠层以下盲区、光照依赖、频次靠人 |
| 固定传感器/摄像头 | 点级 | 实时 | 点位稀疏，覆盖不了全田 |

4. **切入点**：以低成本小车实现**冠层下、厘米级、高频次、不受光照限制**的全田近地巡检，填补无人机/卫星的冠层下盲区。

## 三、系统组成（三大件）

| 组成 | 内容 | 关键点 |
|------|------|--------|
| 巡检小车（端） | 底盘 + 编码器定距 + RGB 相机 + 天气传感器 + 主控 | 每 0.5 m 触发一次采样 |
| 智慧平台（云） | 数据接入 + 分析引擎 + 规则建议引擎 + 可视化 | 全生命周期管理 |
| AI 识别（算法） | YOLO 小模型 + 数据集回流闭环 | 占位算法→预训练→自训 |

## 四、工作流程（完整闭环）

```
① 地块建档：登记地块边界、作物品种、播种日期、生育期参数
② 巡田采样：小车沿垄行行走，编码器每计满 0.5 m 触发一次采样
            （拍照 + 天气快照 + 里程/坐标）
③ 数据上传：按巡检包 JSON 协议上传（离线缓存，WiFi/4G）
④ 自动分析：图像识别（生育期/病虫害）+ 长势评估（绿色覆盖/NDVI）
⑤ 建议生成：分析结果 + 天气 → 规则引擎 → 可追溯农事建议
⑥ 可视化回看：地块地图、巡检轨迹、采样点热力、时间轴回放、建议面板
⑦ 人工复核：存疑照片人工标注 → 数据集回流 → 模型迭代（护城河）
```

## 五、技术架构（端-边-云三层）

```
端（小车）   0.5m 定距采样 + 多源感知 + 数据打包；可下沉轻量模型推理
边（网关）   实时推理 + 离线兜底 + 增量学习（"边缘执行-云演进"）
云（平台）   FastAPI 后端 + Vue3 前端 + PostgreSQL/PostGIS
             分析引擎 → 生长评估 → 规则建议 → 地图可视化
通信        小数据 LoRa / 图像 4G-5G / 接入层 HTTP(现)-MQTT(真车)
```

## 六、核心技术方案

1. **0.5m 定距采样**：轮式编码器脉冲计数（定时器中断）→ 里程换算 → 阈值触发拍照+传感器快照；±2–5cm 精度，支持打滑标定。
2. **多源感知**：RGB 相机（病虫害/生育期）+ 温湿度(DHT22)/光照(BH1750)/风速 + 可选主动光源 NDVI（定量长势，不受光照影响）。
3. **识别路线（小模型）**：占位规则(绿色覆盖率估长势) → 预训练 YOLOv8n 微调（云端）→ 自训数据集 + 端侧量化（RK3588，对标火眼金睛 YOLOv8Ghost 7.7ms/张、86.73%）。
4. **建议引擎（规则可追溯）**：作物 × 生育期 × 天气阈值 → 农事建议（YAML 规则库），每条建议带规则 id；后期可升级"规则兜底 + LLM 生成自然语言报告"。
5. **载体抽象**：小车/无人机/固定监测点统一为"数据源"，同一巡检包协议，平台不绑定单一硬件。

## 七、数据模型（12 张核心表）

User（用户/角色）、Field（地块边界）、Crop（生命周期参数）、Planting（种植批次）、Device（载体）、Patrol（巡检+轨迹）、CapturePoint（0.5m 采样点·一等公民）、WeatherSample（天气快照）、Analysis（每点评估：生育期/长势/病虫害/风险分）、Advice（建议·可追溯）、Rule（规则库）、Annotation（人工复核→数据集回流）。

## 八、创新点（比赛版）

1. **低成本高密度近地巡检**：千元级小车实现 0.5m 采样 + 多源感知，填补冠层下盲区；
2. **监测→诊断→建议全生命周期闭环**：识别结果结合天气生成可追溯农事建议，竞品多止步于"检测报告"；
3. **科学性支撑**：采样密度（0.5m/2m/5m）与病害斑块检测率关系的对比实验——论文与申报书的核心论据。
