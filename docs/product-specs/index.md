# 产品规格索引

> 产品叙事与页面规格的入口。完整内容在编号文档中，此处只做导航与页面清单。

## 用户故事（全文见 docs/04 §3「核心场景」）

1. 建档：地块/作物/种植记录/设备四类基础档案
2. 采集：小车按 0.5m 定距拍照 + 天气采集，巡检包协议上传（对小车端合同：`GET /api/v1/ingest/patrol-schema`）
3. 分析：后台逐点识别生育期/长势/穗数/胁迫，进度可轮询
4. 建议：规则引擎按三层规则自动产出可溯源农事建议
5. 回看：地图轨迹回放 + 时间轴 + 长势着色 + 建议面板
6. 复核：对存疑照片人工标注，结论回流训练数据集（闭环）
7. 总览：/screen 数据仪表盘看全局

## 页面清单（frontend/src/views/）

| 路由 | 页面 | 要点 |
|---|---|---|
| /dashboard | 系统状态 | 后端健康检查 |
| /fields /crops /plantings /devices | 四类档案管理 | 标准 CRUD 表格 |
| /patrols | 巡检任务列表 | 状态/分析状态筛选 |
| /patrols/:id | 巡检回放 | 地图+时间轴+照片大图+人工复核+建议表格 |
| /screen | 数据总览 | 白卡仪表盘，演示用，bare 全屏路由 |

## 设计基调

专业农事 SaaS 亮色风：白卡片、农业绿主色（green-700 系）、高信息密度、装饰克制。
