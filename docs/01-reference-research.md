## 二、学术论文

### 1. 轮式作物生长监测机器人底盘设计与测试 ⭐⭐⭐
- MDPI Agronomy 13(12):3043（用户 URL 正确）：
  https://www.mdpi.com/2073-4395/13/12/3043
- 南京农业大学江晓平团队；全文缓存：`papers/agronomy_jina.md`
- 相关延伸：轮履切换式作物表型信息感知机器人底盘
  http://faculty.njau.edu.cn/zhoudong/en/lwcg/154284/content/439802.htm

**精读要点**
- 底盘：轮式四驱、离地间隙 85–145cm 可调（不压苗）、轮距可调、窄轮 7cm（走行间）
- 动力：轮毂电机 480W/48V×4，车速 0.1–0.3m/s，60V/20Ah 续航约 3h，载荷约 15kg
- 传感器：温湿度/超声波/视觉 + GPS/IMU/霍尔 + **自研 730/810nm 双波段主动光源 NDVI/RVI 光谱传感器**（装底盘下方、距冠层 40–60cm、FOV 垂直向下）
- 测试：越障仿真（10cm 坑/凸起）质心 Z 向位移 1.46–1.78cm（体高 1.3–1.6%），田间实测 1.51cm；NDVI 可预测 LAI/叶干重/叶氮积累
- 未涉及 RGB 相机与固定间隔拍照
- **借鉴**：0.1–0.3m/s 车速与 0.5m 采样节拍天然匹配；主动光源光谱是最可靠的长势传感器（不受自然光照影响）

## 三、对 AgriScout 的设计启示（精读后定稿）

1. **端-边-云三层架构直接采纳**（Sensors 论文）：端=小车（压缩/特征提取，能耗仅 8–15%）；边=田间网关/车载计算机（轻量 YOLO 实时推理 + 离线兜底 + 增量学习，"边缘执行-云演进"）；云=Web 平台（跨生育期建模、建议生成）
2. **通信分路**（Frontiers 综述）：天气/状态小数据走 LoRa/LoRaWAN，图像走 4G/5G，接入层用 MQTT；弱网时由边缘轻量模型兜底
3. **小车选型硬指标**（南农论文）：轮式四驱 + 高离地 85–145cm + 可调轮距窄轮不压苗 + 车速 0.1–0.3m/s（与 0.5m 采样节拍匹配，1.7–5s/点）
4. **长势评估双通道**（南农论文）：主动光源 730/810nm NDVI/RVI 光谱传感器（不受光照影响、可定量 LAI/生物量/氮）+ RGB 相机（病虫害/阶段识别）
5. **识别方案**（火眼金睛）：RK3588 + YOLOv8Ghost 轻量化（7.7ms/张、86.73%），自建垂直标注数据库是关键——平台必须做"标注数据回流"闭环
6. **业务闭环**（神农卫田）：识别→诊断→决策（结合天气给防护/施药建议），农户手机实时看数据——建议引擎是 AgriScout 的差异化核心
7. **载体抽象**（神农卫田 + Frontiers UAV-UGV 协同）：小车/无人机/固定监测点统一抽象为数据源，避免绑定单一硬件
8. **演进预留**（Frontiers 综述）：数字孪生 / 联邦学习 / LLM 农事报告
