==================================================
AgriScout 嵌入式学习路线（成员A专用）
==================================================

原则：以"10 月装车"倒排，只学本项目用得上的。
每项知识都绑定车上一个具体功能。

--------------------------------------------------
一、知识清单（按优先级）
--------------------------------------------------

【P0 必须会】小车跑起来 + 0.5m 定距采样的全部基础

1. 单片机 C 基础：GPIO 输入输出、串口打印调试
   -> 用到车上哪：一切控制的基础 + 调试手段
   -> 学习时间：1 周

2. 定时器中断
   -> 用到车上哪：编码器脉冲计数（定距采样的核心）
   -> 学习时间：3-5 天

3. PWM 输出
   -> 用到车上哪：电机调速
   -> 学习时间：1 天（与第 1 项一起学）

4. 电机驱动板（TB6612/L298N）接线与逻辑
   -> 用到车上哪：行走、差速转向
   -> 学习时间：2 天

5. 编码器原理：霍尔/光电，脉冲→里程换算
   -> 用到车上哪：0.5m 定距触发（作品核心创新点）
   -> 学习时间：3 天

6. 串口协议（UART，自定义帧格式）
   -> 用到车上哪：单片机→树莓派发触发信号
   -> 学习时间：2 天

7. I2C 总线
   -> 用到车上哪：光照传感器 BH1750
   -> 学习时间：1 天

8. 单总线（OneWire）
   -> 用到车上哪：温湿度 DHT22
   -> 学习时间：1 天

【P1 建议会】联调与演示必需

9. 树莓派 Linux 基础：SSH、systemd 开机自启、Python
   -> 用到车上哪：采集主控

10. 树莓派摄像头：picamera2/libcamera 拍照
    -> 用到车上哪：采样拍照

11. Python 串口读数据 + requests 上传
    -> 用到车上哪：收触发信号、打包上传平台

12. 电源：18650 串并联、降压模块(5V/12V)、电量估算
    -> 用到车上哪：整车供电（最容易被忽视）

【P2 加分叙事】答辩时"会"比"用"重要

13. RTOS 概念（FreeRTOS 任务/中断）
    -> 答辩价值：评委问"实时性怎么保证"时能答

14. 4G 模块 AT 指令
    -> 答辩价值：演示之外讲"田间无 WiFi 场景"

15. GPS NMEA 语句解析
    -> 答辩价值：定位叙事（量产版用 RTK 的铺垫）

--------------------------------------------------
二、路线选择：STM32 还是 Arduino？
--------------------------------------------------

【STM32（CubeMX+HAL）】
优点：技术含量高，大挑评委认；中断/定时器能力强；
      以后就业有用
缺点：学习曲线陡，2 个月调通时间紧
定位：主路线（你已会一点嵌入式）

【Arduino Nano / ESP32】
优点：2 周能跑通，库齐全
缺点：评委可能觉得"玩具"、实时性叙事弱
定位：兜底方案（STM32 卡住时切换，定距逻辑代码
      思路几乎一样，只是中断实现不同）

建议：主攻 STM32；如果 9 月底定距触发还没调通，
立刻切 Arduino Nano 兜底。

--------------------------------------------------
三、时间安排（现在到 10 月装车）
--------------------------------------------------

08月底-09月中
  内容：GPIO/PWM/定时器中断/电机驱动跑起来
  验收：能遥控小车前进后退转向

09月中-09月底
  内容：编码器里程换算 + 三个传感器读数
  验收：串口打印"走了0.50m，触发！"+ 温湿光数值

09月底-10月初
  内容：树莓派拍照 + 串口收信号 + 打包上传
  验收：树莓派收到触发→拍照→生成巡检包 JSON

10月
  内容：供电整合 + 装车联调
  验收：小车走 10 米，平台收到 20 个采样点

每段都有硬验收标准，不达标不进入下一段。

--------------------------------------------------
四、学习资源
--------------------------------------------------

- STM32：B 站「江科大自化协」入门（口碑最好）
  + 正点原子/野火教程进阶
  + CubeMX 图形化配置省时间
- 编码器：淘宝电机编码器模块自带资料，
  搜"霍尔编码器测速 STM32"
- DHT22/BH1750：对应库的示例代码直接改
- 树莓派：官方文档 + picamera2 官方示例

调试工具（必买，共约 100 元）：
- USB-TTL 串口模块（15 元，必买）
- 万用表（必买）
- 逻辑分析仪（30 元，可选，看编码器波形神器）

--------------------------------------------------
五、给评委讲故事时的"知识地图"
--------------------------------------------------

问辩时按这个链条答：

编码器脉冲
  -> 定时器中断计数
  -> 里程换算
  -> 0.5m 阈值触发
  -> 串口通知主控
  -> 拍照 + 传感器快照
  -> 打包上传

每个环节都亲手调过、能讲原理，问辩就稳了。
评委喜欢顺着这条链问，答得越细，科学性分越高。
