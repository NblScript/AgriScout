# 0005 · 申报书软件闭环补齐

## 状态
已完成（2026-09-25）——软件侧闭环、设备协议适配和验收测试完成；真实硬件与田间模型效果仍按 M7 联调计划验证。

## 背景
申报书的软件目标已经超出当前 M0–M6 的模拟闭环：还需要区域级风险预测、主动学习与复巡任务、预警随访证据、数据集与模型评估闸门，以及设备任务/状态接口。现有后端已有采样、逐点分析、规则建议、标注和报告基础，因此采用增量方式补齐领域服务、持久模型和 API，保持巡检包合同与异步分析红线不变。

## 决策记录
- 风险预测、主动学习和证据反馈先实现为纯函数服务，再由 API/数据库持久化调用，便于离线重放和单元测试。
- 预测结果必须保存模型版本、时间窗、依据和质量门控信息；缺失或低质量观测不得静默当作健康标签。
- 复巡任务与标注任务统一使用可解释的候选评分，但保留随机抽查选项，避免只验证高风险样本。
- 硬件相关能力先提供 HTTP 任务、心跳、事件和故障注入接口，不伪造真实编码器、RTK、天气或急停结果。
