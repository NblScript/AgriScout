# 0011 · H3 真实数据验证：NWRD 图块上的主动学习选样对比

## 状态
已完成（2026-09-27）。前置：计划 0008（H3 离线重放实现）、0010（NWRD 数据准备）。

## 背景
申报书 H3（主动学习选样能以更少标注达到同等性能）目前只有仿真结果，且两季结论不一致：季二联合策略以 100 个标注
达到全量 90%，季一随机选样更优。申报书的验证体系写明以公开真实田间数据验证主动学习选样。本计划在 NWRD 的真实
条锈病图块上重跑 H3，与仿真用同一套选样实现，结论可以直接对照。

## 决策记录
- **复用同一套 H3 实现**：`services/offline_replay.h3_active_learning`（平台 label 打分 + 代表性 + 重复惩罚），
  只做两处通用化：可指定固定测试集（`test_folds`），无时序数据时「变化量」信号取 0。ml 端只负责提取特征并导出样本文件，
  后端工具读文件运行，ml 与后端之间只通过文件交接。
- **特征不能泄漏标签**：用 ImageNet 预训练、未在 NWRD 上训练过的 YOLOv8n-cls 提取图块特征，PCA 降到 32 维
  （只在候选池上拟合，无监督）。不用 rust-cls-v1 提特征——它见过全部训练标签，会让所有策略看起来都很好。
- **样本**：候选池从官方训练集图块按固定种子抽 4,000 块（纯 Python 实现下控制运行时间）；测试集为官方测试集全部 1,980 块。
  「区域」取来源整图：同一批次每张图最多选一块，已标过的图打折，对应仿真里的同区域重复惩罚。
- **参数**：初始 20 个标注、每轮 +20、预算 200，5 个随机种子；学习器与仿真相同（L2 逻辑回归）。
  指标：测试集 PR-AUC 学习曲线、曲线下面积、达到全量候选池 90% / 95% 所需标注数。

- **逐种子统计**（实跑中追加）：5 个种子时种子间标准差（约 0.05）大于策略差距，改为 20 个种子，
  曲线下面积相对随机取配对差，报告自助法 95% 置信区间与胜出种子数。
- **阳性稀少条件**（看到原始比例结果后追加，属事后分析）：NWRD 图块锈病约占三分之一，而田间发病罕见
  （模拟季患病率 2–4%）。`--pool-prevalence` 按固定种子把候选池锈病抽稀到 10% / 5% / 2%（阴性与测试集不动），
  并换一批抽样重跑 5% 检查稳健性。平台打分权重不因本结果改动。

## 结果
特征：ImageNet 预训练 YOLOv8n-cls 冻结特征，PCA 32 维（解释方差 0.84）。候选池 4,000 块训练图块，测试集为官方测试集
1,980 块（锈病 736）。学习器上限（全量候选池 L2 逻辑回归）PR-AUC ≈ 0.75（对比微调后的 rust-cls-v1 为 0.91）。
初始 20、每轮 +20、预算 200、20 个种子。

| 候选池锈病比例 | 联合策略 − 随机（曲线下面积，95% CI） | 胜出种子 | 仅不确定性 − 随机 | 预算 200 时 PR-AUC 联合 / 随机 | 达到随机@200 所需标注（联合 / 不确定性） |
|---|---|---|---|---|---|
| 32.5%（NWRD 原始） | +0.003（−0.016 ~ +0.023） | 8/20 | +0.008（−0.011 ~ +0.028） | 0.649 / 0.646 | 200 / 180 |
| 10% | **+0.038（+0.008 ~ +0.067）** | 13/20 | +0.016（−0.021 ~ +0.053） | 0.671 / 0.588 | **120** / 140 |
| 5% | **+0.057（+0.027 ~ +0.089）** | 14/20 | +0.031（−0.011 ~ +0.074） | 0.707 / 0.563 | **100** / 120 |
| 5%（另一批抽样） | **+0.052（+0.015 ~ +0.087）** | 14/20 | +0.023（−0.018 ~ +0.063） | 0.645 / 0.519 | **100** / 120 |
| 2% | **+0.049（+0.017 ~ +0.079）** | 17/20 | +0.035（−0.015 ~ +0.083） | 0.660 / 0.540 | **100** / 120 |

**结论**：
- 阳性不稀少时（约三分之一），三种策略没有可分辨的差别，随机选样已足够。
- 阳性稀少时（≤ 10%，更接近田间），平台联合策略在每一组都显著优于随机；达到随机选样 200 个标注的效果，
  联合策略只需 100–120 个（节省 40–50%）。仅不确定性始终略好于随机但不显著，说明风险与代表性项有增益。
- 与仿真 H3 的关系：仿真两季结论不一致（季二联合占优、季一随机更优），真实数据给出了更明确的条件——
  优势取决于阳性稀少程度。
- 局限：稀少条件为事后追加（已用多比例、重抽样检验稳健性）；学习器为冻结特征 + 逻辑回归，不是微调网络；
  样本为 NWRD 图块而非小车照片，田间标注成本与图块标注不同。结论应在试验田随访数据上复验。
