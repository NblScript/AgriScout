# 0008 · 多日期病害扩散模拟 + 离线重放评估 + 随访指标

## 状态
已完成（2026-09-25）。来源：申报书方案评审之后的「软件端现在能做」A 类前三项。决策登记为 D11。

## 背景
真车数据要到 2027 年春天才有，但创新一、二的实验流程现在就可以先用模拟数据跑通：
「多日期采集 → 带历史的风险预测 → 复巡/标注策略比较 → 随访 → 指标」。目前卡在三处：

1. 模拟器每次只生成一趟巡检，同一区域没有时间序列，病害也不会扩散，时序特征和空间特征都无从开发；
2. 没有离线重放：无法在同条件、同预算下比较「固定路线 / 只按风险 / 联合策略」（H2）与标注选样策略（H3），也无法做特征消融（H1）；
3. 随访只能记录，平台不会根据随访结果算 PR-AUC、Brier、固定误报负担下的召回率和提前量。

另外，风险预测每点只看本次观测（审查第 19 项），多日期数据进来也用不上。

## 决策记录
- **区域关联 v0 = 地块局部网格分箱**：以地块边界外包框西南角为原点换算米制坐标，默认 2.5 m 网格，
  区域键 `field-{id}/grid2.5m/{ix}_{iy}`。这只是过渡方案，适用于模拟器和 RTK 级坐标；
  巡检包 v2 的 `observation_key`（计划 0007 P0-1，垄号 + 桩号）上线后优先采用协议值。不改巡检包协议。
- **风险预测改用区域级输入**：本次观测与历史观测都取区域内各点风险分的最大值（早期病斑是局部的，均值会被稀释），
  回看 30 天内的历史巡检。计算方式变了，默认模型版本升为 `risk-heuristic-v2`（旧版本号下的历史结果仍可复现、互不混淆）。
- **离线重放放在后端**：写成纯函数服务（`services/offline_replay.py`）加 CLI（`app/tools/replay_eval.py`），
  直接复用平台的主动学习打分（`active_learning.rank_candidates`），评估的就是平台自己的策略。
  真值由模拟器导出 JSON 文件；将来真实数据用随访结果当真值。
- **H1 用可学习的逻辑回归**，不用手调权重的启发式：按空间条带分组交叉验证，4 组特征集
  （仅环境 / 仅图像 / 图像 + 历史 / 全部，其中「全部」含空间邻域），与申报书「从可解释的逻辑回归开始」一致。纯 Python 实现，不引入 numpy。
- **H2 的复巡价值模型**：基础巡检只能在病斑达到一定严重度后才看得出来；定点近距离复巡能更早看出来。
  比较各策略在相同复巡预算下提前确认的病害区域数量，以及漏查的比例；同一区域只计一次。
  基础巡检照片已明显异常（区域风险分 ≥ 0.2）的区域不占复查预算。
- **H2 用现时检出模型，不用 H1 的预报模型**：复查有没有收获取决于「此刻有没有近距离可确认的病斑」，
  不是「三天后会不会显症」。初版误用 H1 模型，而且只给未显症的区域打分，结果「只按风险」比随机还差；实跑时发现并改正。
  随机策略取 20 次平均（单次随机方差太大）。
- **随访口径**：阳性 = 1，阴性 = 0；处置过的样本按删失处理；证据不足、未知、待定或没有随访的不进分母。
  校准按时间先后拆分：前半段拟合等渗回归，后半段评估，避免同一批数据既拟合又评估。
- **模拟季的日期放在过去**：让预测窗口在「现在」之前全部结束，模拟农技员的阴性随访能通过 D10 校验。

## 最终结果

后端 pytest 175 passed（本计划新增 23 条）；rover + simulator unittest 14 OK。默认参数（10 垄 × 30 m、36 天、每 3 天一趟、
H = 3 天、2.5 m 区域网格，65 个区域）跑了两个种子，每季约 4–6 分钟：

| 结果 | 种子 7 | 种子 11 | 两次是否一致 |
|---|---|---|---|
| 首次显症样本（阳性 / 总数） | 26 / 719 | 16 / 735 | — |
| H1 PR-AUC：仅环境 / 仅图像 / 图像+历史 | 0.049 / 0.050 / 0.063 | 0.023 / 0.025 / 0.048 | 都接近患病率 |
| H1 PR-AUC：全部（含空间邻域） | 0.126（95% CI 0.055–0.269） | 0.279（0.054–0.473） | 一致：邻域信息带来主要增益 |
| H1 平台启发式 v2 | 0.066 | 0.021 | 一致：接近随机，不适合预报首次显症 |
| H2 确认病害区域：随机 / 固定路线 / 只按风险 / 联合 / 启发式 v2 | 4.3 / 7 / 15 / 14 / 16 | 1.9 / 3 / 10 / 7 / 9 | 一致：按风险排序是随机的 3–5 倍 |
| H2 路程（米）：只按风险 / 联合 | 596 / 470 | 579 / 447 | 一致：联合策略路程短约 20% |
| H3 学习曲线下面积：随机 / 不确定性 / 联合 | 0.199 / 0.163 / 0.172 | 0.223 / 0.184 / 0.294 | **不一致**：排名互换 |
| 平台指标（模拟随访）阳性数 / 提前量已预警 | 8 / 0 | 3 / 0 | 随访抽样只拿到个位数阳性 |
| 等渗校准后 Brier（时间后半段） | 0.107 → 0.060 | 0.064 → 0.029 | 一致：校准明显改善 |

**怎么读这些结果**
- H1 的空间邻域增益是模拟器**按设计放进去的**（潜伏期 + 空间扩散）。它证明的是评估流程能测出一个确实存在的信号，
  不是真实病害规律的证据。
- 启发式 v2 只汇总本区域的风险分，对「首次显症」几乎没有预报能力，按 0.5 阈值一次都没有提前预警。
  下一步应该用 H1 的全特征逻辑回归训练一个 `risk-lr-v1`，替换启发式，走模型评估闸门发布。
- H3 在每季 16–26 个阳性的规模下分不出策略优劣；每季只随访 35% 的区域时，平台侧指标只有个位数阳性。
  这正是申报书「事件不足只能报告流程验证」的情形。真实试验要么扩大地块或小区数，要么让随访覆盖更多参照区域。
