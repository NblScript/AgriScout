## 背景
申报书的创新一、二依赖跨日期的观察区域身份、连续环境记录、图像质量信号和可靠的采集端持久化，这些当前代码里缺失或只是占位值。
建档时实测（1234 点模拟巡检）：1197 条风险预测的趋势全是 `unknown`、置信度全是 0.295；50 条复巡任务全部以「图像质量低」为理由，
但从未测过图像质量。此后 D11（区域网格关联）让模拟数据有了区域历史，D13 把理由改为「证据质量不足」；
但真车坐标是按步长推算的直线，网格关联用不上，图像质量仍未实测。
小麦病害的观测窗口大约只有 2027 年 3–5 月一次，所以 P0 必须在越冬期（2026-11 ~ 2027-02）完成。
P0-1/P0-3 会改动巡检包协议（红线 4）：schema 导出、simulator、rover 三处需要同步，并附带新测试。

## 剩余项设计（2026-10-09）
**P1-7 数据集分组划分与评估重算**
1. 冻结快照升为 `agriscout.dataset.v2`：每行加 `field_id`、`field_date`（D9 田间日期）、`observation_key`、`group`、`split`。
   `source_filter` 增加 `field_id`、`date_from`、`date_to`（田间日期，含两端）。
2. 划分（`group-shuffle-v1`）：同一组整组进同一份，组键默认「地块 + 田间日期」，可选「地块」；组按 sha256(种子|组键) 排序，
   依次填满测试、验证，其余为训练（默认 0.15 / 0.15 / 0.70，按行数）。冻结请求可带 `split: {seed, group_by, ratios}`，缺省种子 0。
   划分参数、各份行数与组列表写进 `snapshot_summary.split`；阳性标签（`label_schema.positive_labels`，缺省按病害标签）也在冻结时写定。
3. 模型评估改为提交逐条预测 `predictions: [{annotation_id, score}]` 和阈值；平台核对预测的样本正好是快照里该 split 的全部行，
   重算 precision / recall / f1 / pr_auc 存 `platform_metrics`，客户端自报的 `metrics` 只留作对照。
4. 审批闸门：只认平台重算的 test 指标；测试组至少一个阳性、一个阴性；没有划分的旧快照不能审批（重新冻结一个新版本）。
5. 迁移 0017：`model_evaluations` 加 `predictions`、`platform_metrics` 两列。前端研究闭环页：按地块建草稿、冻结时填种子、
   列表显示三份行数和平台指标。

**P1-9 盲法复核**（P1-7 合并后细化）：复核时隐藏模型分数、入选原因、任务类型；待复核队列混入随机对照株并打乱；
标注和随访记录「是否盲评」。

**P0-2 时钟**（P1-9 之后细化）：rover 建巡检时记录本机时钟是否已同步、联网时与平台的时间差，随包上传；
平台对未来时间戳、未同步时钟、心跳时间偏差过大给出告警。协议变更按红线 4 同步 schema 导出、模拟器与 rover。

## 决策记录
- （作废，D16）区域粒度：建议用「垄号 + 桩号分段 2–5 m」，编码器加垄头标记（二维码或反光标）做关联，不依赖 RTK。
- （已定，随 P0-3 迁入计划 0016 阶段 B）上传方式：建议两步走，先按哈希逐张传照片（服务端已有的跳过）、再提交只含 URL 的元数据包；与 v2 的 `client_package_id` 一起落地。
- （作废，D16 定为黄瓜霜霉病）病种选择看三条：症状在车载视角能看到；有发病中心并向外扩散；当地常年发生。以当地植保站历年资料为准。
  事件数不足时考虑病圃、品种区试小区或人工接种。
- （建议）策略比较以离线重放为主证据（全覆盖巡检上模拟各策略，同条件同预算），实车只验证补拍与多视角增量；
  主动学习报告多种子学习曲线与置信区间。
- （建议）创新三落到「标签口径会让指标偏多少」：未复查当阴性、窗口未结束记阴性、处置后未发病当阴性，分别算 PR-AUC 与 Brier 偏差。
- 已定（D10）：随访标签的时间口径。阴性须等预测窗口结束；阳性的事件时间须落在窗口内。
- 已定（2026-10-01）：参赛目标为 2027 第二十届大挑科技发明制作 A 类主体赛，未参加 2026 小挑；定位为「有研究支撑的应用型发明」，
  田间试用与应用证明和实验数据同等重要。规则要点、类别选择与合规清单见 `docs/design-docs/competition-rules.md`。
- （待确认）2 名高级职称指导教师（章程第二十二条，报名硬门槛）。
- 已定（P1-7，2026-10-09）：口径见决策 D24。研究闭环页的数据集草稿改按所选巡检的地块建（原来按单趟巡检，单趟只有一天、分不出测试组）；
