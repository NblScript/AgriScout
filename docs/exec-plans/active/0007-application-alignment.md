# 0007 · 申报书对齐：真车采数前置改造

## 状态
待团队确认优先级后开工（2026-09-25 建档）。来源：[申报书方案评审](../../reviews/2026-09-25-application-review.md) 第三节。

## 背景
申报书的创新一、二依赖跨日期的观察区域身份、连续环境记录、图像质量信号和可靠的采集端持久化，这些当前代码里缺失或只是占位值。
实测：1197 条风险预测的趋势全是 `unknown`、置信度全是 0.295；50 条复巡任务全部以「图像质量低」为理由，但从未测过图像质量。
小麦病害的观测窗口大约只有 2027 年 3–5 月一次，所以 P0 必须在越冬期（2026-11 ~ 2027-02）完成。
这里的 P0-1/P0-3 会改动巡检包协议（红线 4）：schema 导出、simulator、rover 三处需要同步，并附带新测试。

## 决策记录
- （待定）区域粒度：建议用「垄号 + 桩号分段 2–5 m」，编码器加垄头标记做关联，不依赖 RTK。
- （待定）上传方式：建议两步走，先按哈希逐张传照片、再提交只含 URL 的元数据包；与 v2 的 `client_package_id` 一起落地。
- 已定（D10）：随访标签的时间口径。阴性须等预测窗口结束；阳性的事件时间须落在窗口内。
