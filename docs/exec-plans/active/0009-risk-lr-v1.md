# 0009 · risk-lr-v1：可训练的逻辑回归风险模型（暂不含环境特征）

## 状态
进行中（2026-09-25 建档）。前置：计划 0008（模拟季、离线重放、区域历史）。

## 背景
计划 0008 的两季模拟显示：平台启发式 v2 对「首次显症」几乎没有预报能力（PR-AUC 接近患病率，0.5 阈值下 0 次提前预警）；
加入邻近区域特征的逻辑回归在两季上 PR-AUC 分别为 0.20 和 0.26。本计划把这个模型做成平台可用的正式版本：
离线训练 → 导出带版本号的模型文件 → 生成风险预测时可选用 → 用随访指标评估。

环境特征暂不使用：平台还没有存连续气象记录的地方（计划 0007 P0-4），车载单点读数不能替代连续记录（申报书 7.1）。
模拟中环境特征的增益也很小。气象站接入后再出 v2。

## 决策记录
- **特征**：只用 5 个图像/时空特征：本区域当前风险分、回看窗口内的历史最高、相对上一趟的变化量，
  以及邻近 8 个区域的当前最大风险分和变化量。
- **训练与线上共用同一个特征函数**（`services/risk_features.py`）：离线重放和线上预测都调用它，
  用测试锁住两边对同一数据算出的特征完全一致，防止训练—上线偏差。回看窗口两边统一为 30 天。
- **逻辑回归实现移到 `services/logistic.py`**（带回溯线搜索的牛顿法），离线重放和线上共用。
- **模型文件不进仓库**：`backend/models/<版本>.json`（gitignore，红线 7），包含特征名、标准化参数、系数、训练目标
  （目标事件、窗口 H、网格边长、回看天数）、训练数据摘要、交叉验证指标和文件 SHA-256。
- **线上调用**：`model_version` 以 `risk-lr-` 开头时加载同名模型文件。版本号按白名单正则校验，防止路径穿越。
  请求的目标事件、窗口 H、网格边长、回看天数必须与模型训练时一致，否则 422：换了目标的预测不能冠用这个模型的名字。
- **等级划分用相对风险**：概率 ≥ 训练集患病率的 5 倍为 high，≥ 2 倍为 medium。罕见事件下固定的 0.33/0.66 阈值会让所有点都是 low。
  置信度取 |2p − 1|（越接近 0 或 1 越确定），并在 evidence 里说明。
- **不强制审批才能使用**（与现有分析器切换一致），但每条预测的 evidence 记录模型的审批状态
  （是否有同名同版本且已批准的模型评估），答辩和追溯时可查。
- **跨地块测试**：训练 CLI 给了两块以上地的真值时，额外报告「留一块地」的测试结果。这比同一块地内的交叉验证更接近申报书 8.3 的独立测试要求。
