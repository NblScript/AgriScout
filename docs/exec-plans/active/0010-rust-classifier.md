# 0010 · rust-cls-v1：基于公开田间数据的条锈病识别模型

## 状态
进行中（2026-09-27）。前置：计划 0002（麦穗检测管线）、0008/0009（风险预测以逐点风险分为输入）。

## 背景
平台现有识别只有两部分：`wheat-yolo-v1` 数麦穗估长势（Global Wheat Head，单类），以及颜色统计给出的
「叶色异常斑块」和风险分。风险预测、复巡、随访的起点都是逐点风险分，而它目前来自颜色启发式，
不是病害模型。本计划用来源明确的公开真实田间数据训练条锈病识别模型，让病斑位置和风险分来自模型。

条锈病与模拟季的目标事件一致（条锈病样首次显症）；申报书也写明「以来源明确的公开真实田间病害数据集验证病害识别」。

## 决策记录
- **数据**：NWRD v1.0（NUST Wheat Rust Disease），Zenodo DOI 10.5281/zenodo.21672928，CC-BY-4.0，
  作者 Anwar & Shafait（Sensors 2023, 23(15):6942）。100 张自然田间条件下的多叶片高分辨率图像，带条锈病像素级掩膜，
  官方已分训练/测试集。下载脚本校验 MD5；数据与切块产物不入库（`ml/data/*` 已 gitignore）。
- **任务形式：图块分类，而非分割或检测**。用掩膜给图块打标签（锈病 / 健康），训练 YOLOv8n-cls：
  与 `wheat-yolo-v1` 同一套 ultralytics 工具链，后续导出到 TX2 的路径相同；推理时把小车照片切成网格逐块判断，
  既能给出病斑位置（图块框），也能给出发病面积比例。
- **标签口径**：图块内锈病像素占比 ≥ 0.5% 记为锈病，为 0 记为健康，介于两者之间的不参与训练（边界样本标签不可靠）。
  原定 2%，实测 NWRD 掩膜只标孢子堆像素，整图锈病占比中位数仅 0.35%（最高 3%，每张图都有锈病）；
  短边 1/3 的图块中 45% 完全无锈病、33% ≥ 0.5%，0.5% 约相当于 94×94 像素的可见病斑。
  多尺度切块，缩放到 224 输入，兼顾不同拍摄距离。
- **划分按整图，不按图块**：官方测试集只用于最终评估；从官方训练集按固定种子留出约 10% 整图作验证集。
  同一张图的图块不会同时出现在训练和测试中。
- **评估**：测试集图块级精确率、召回率、F1、ROC-AUC、PR-AUC；整图级「是否检出锈病」；以及模型估计的发病面积比例
  与掩膜真值的秩相关。指标与数据来源、许可证、模型文件 SHA-256 一起写入导出的说明文件。
- **平台接入**：新增可选配置 `DISEASE_MODEL_PATH`。配置后分析器把照片切成网格逐块推理，
  输出一条汇总检出（类型 `stripe_rust`，置信度 = 最高图块概率，附阳性图块框与面积比例），
  逐点风险分改由模型给出；颜色胁迫检出保留为独立类型，只作非病害胁迫提示，不再决定风险分。
  检出格式沿用现有字段，规则引擎（有检出即触发实地复核建议）、巡检包协议、前端均不需要改动。
  麦穗模型改为可选（`YOLO_MODEL_PATH` 为空时不做数穗），两个模型可单独或同时启用。
- **局限（写入模型说明文件）**：NWRD 为近距离叶片图、单一病害、采自巴基斯坦，与小车俯拍冠层存在域差；
  模型输出是候选检出，须人工复核；小车照片到位后用自采标注数据微调并重新评估。
